Server-side refresh & caching

Because api.taskmarket.dev does not send cross-origin browser headers, data is fetched on the server every hour by GitHub Actions (cron: '17 * * * *') into data/snapshot.json and served over GitHub Pages HTTPS with CDN caching (≥ 60s).

Endpoints queried (Tempo 4217 & Base 8453) /api/market/stats?chainId=… /api/stats/breakdowns?chainId=… /api/stats/platform-time-series?chainId=… /api/stats/activity-heatmap?chainId=… /api/stats/activity-feed?chainId=… /api/tasks?chainId=…&sort=newest&limit=100
Scope & definitions

Distinct weekly posters, poster concentration (Top-1, Top-5, HHI), and mode-to-outcome flows are computed directly from paginated /api/tasks requester addresses per chain. Headline totals marked Platform reflect platform-wide API counters; totals marked Chain reflect chain-specific counters.
